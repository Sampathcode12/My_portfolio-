BookMyRoom (HottelApp) — Test Results & QA Report

App: HottelApp (com.example.hottelapp) · Version: 1.0 · Platform: Android · Report date: June 2026

1. Testing Overview

Manual functional testing was performed on login, room browsing, booking, service reservations, and admin management flows. Unit and instrumented test scaffolds are included in the project; app-specific automated tests can be expanded in future iterations.

2. Types of Testing Performed

  • Functional testing — admin and customer login, registration, dashboards
  • CRUD testing — rooms, services, users, and about content management
  • Booking testing — room bookings and service reservations with pending status
  • UI testing — navigation across admin and customer activity flows
  • Data validation — SQLite persistence for users, rooms, bookings, and images
